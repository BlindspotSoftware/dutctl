# Documentation

The documentation of dutctl is published at <https://blindspotsoftware.github.io/dutctl/>, arranged for its users,
admins and module developers.

This folder holds its pages; the module READMEs and the project documents at the root of the repository are pages too.
[site/data/pages.yaml](../site/data/pages.yaml) says where each file appears on the site, and
[CONTRIBUTING.md](../CONTRIBUTING.md#documentation-style-guide) where a new text goes. The decision records are in
[decisions](./decisions/README.md).
